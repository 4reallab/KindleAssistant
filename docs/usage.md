# Kindle助手 · 使用说明

## 目标设备

- Kindle Paperwhite 3（Readom，Android 8.1 / API 27）
- `minSdk 27`、`targetSdk 27`，不依赖 Google Play 服务

## 构建

在项目目录执行：

```bat
scripts\build.bat
```

产物：`app\build\outputs\apk\release\KindleAssistant.apk`（已签名，可直接安装）。

Gradle 发行包、依赖缓存、SDK 都在项目目录内：

- `gradle\gradle-8.7-bin.zip`
- `.gradle-home\`
- `android-sdk\`

构建脚本使用 Android Studio 自带 JBR（JDK 21）。本机 GraalVM 17 的 `jlink` 缺少 AGP 需要的模块，命令行构建时需同样指定：
`JAVA_HOME="D:\Program Files\Android\Android Studio\jbr"`。

Android Studio 可直接打开仓库根目录（本机的工程目录为 `G:\Projects\kindle\KindleAssistant`）。

## 安装与桌面图标

```bat
D:\Android\android-sdk\platform-tools\adb.exe install -r app\build\outputs\apk\release\KindleAssistant.apk
```

设备实测：`Kindle Paperwhite 3 / pw3 / Android 8.1 / SDK 27 / 1072x1448 / 300dpi`。

首次启动会请求存储权限，请允许。随后系统会弹出「添加到主屏幕」确认框，点「自动添加」即可把 **Kindle助手** 图标放到 Launcher 主页。如果当时点了取消，可在「全部应用」里长按图标手动添加。

## 主界面

- 并排三个大按钮：**图片**（接收与查看）、**待办事项**（清单与计时）、**电子台历**（日历与天气）。
- 底部状态行同一行显示接收服务状态与局域网地址（如「接收服务：运行中　http://192.168.31.192:8088/」），下方是二维码和启动/停止按钮。
- 二维码指向功能门户页，手机扫码后可进入「上传图片」或「待办事项」。
- HTTP 服务监听 `0.0.0.0:8088`，仅建议在可信局域网内使用。

## 图片功能

1. Kindle 与手机连接同一 Wi-Fi，服务显示 `http://<Kindle IP>:8088/`。
2. 手机扫码 → 上传图片，可一次选多张。
3. Kindle 收到后自动全屏打开最后一张。文件永久保存在公共图片目录 `内部存储/Pictures/`（由系统媒体服务写入，系统相册可见）。这台 Readom 不允许普通应用创建公共子目录，因此文件名带时间戳前缀，例如 `20261125_115336_967_test.png`。
4. 点主界面「图片」进入宫格，点击缩略图全屏查看。
5. 全屏时：
   - 点击图片显示「旋转 90°」按钮，每点一次顺时针旋转 90°，可连续旋转；
   - 10 秒无点击，旋转按钮自动消失；
   - 左右滑动切换图片；
   - 从屏幕左边缘或右边缘向内滑动返回宫格。

## 待办事项

设备端点「待办事项」进入；手机扫码或电脑浏览器打开 `http://<Kindle IP>:8088/todo` 也可操作。

- 三个标签页水平排列：**未完成 / 已完成 / 已删除**，设备端和网页端一致；标签上直接显示该分类的事项数量。
- 列表项下方用独立一行小字显示时间：三个标签页都显示添加时间；已完成/已删除在该行同时显示完成/删除时间（例如「完成：2026-11-25 13:09:41　添加：2026-11-25 13:09:41」）。
- 支持添加、修改、删除；每行右侧的「⋯」菜单提供修改与删除，删除前会二次确认。删除为软删除，可在「已删除」中恢复；在「已删除」里再次删除为彻底删除（同样需确认）。
- 待办数据保存在应用内部文件 `files/todos.json`，设备端与网页端共享，重启后保留。
- 点击待办条目进入计时页面。
- 计时自然结束或手动点「结束」后，页面显示本次耗时与累计耗时，并在待办列表的小字行追加「累计耗时：HH:MM:SS」；不自动改变待办状态。点「返回待办」回到列表。

网页端增删改完成后会 303 跳转回待办列表，并保留当前标签页。

## 计时页面

- 快捷按钮：5 分钟、10 分钟、15 分钟、30 分钟、1 小时。
- 滑条自定义范围：1～60 分钟。
- 按钮：开始 / 暂停 / 结束；暂停后「开始」变为「继续」。
- 退出计时页（返回、切到别的页面）会自动暂停并保存剩余时长；再次进入显示暂停的沙漏，点「继续」接着倒计时。点「结束」会清除这次计时，下次进入回到设置页。
- 窗口底部持续显示当前日期和时间（为保护墨水屏，不显示秒；对齐系统时钟的整分钟刷新，与状态栏时间一致；倒计时到点由独立定时器精确触发，不受刷新间隔影响）。
- 点击开始后，快捷按钮与滑条隐藏，显示沙漏：
  - 上仓大字显示剩余时间，下仓大字显示已消耗时间，均以「分钟」为单位、不显示秒、每分钟刷新；标签与时间分行摆放并带白底；上仓文字靠近漏斗顶部、下仓文字靠近漏斗底部，白底框不遮挡两侧斜边；
  - 上仓沙子逐渐减少，下仓沙子逐渐增多，沙子漏下速度与倒计时呈线性关系；
  - 暂停时沙漏停止，沙流线消失。
- 计时结束页的「本次耗时 / 累计耗时」为静态展示，保留到秒（如 `00:00:25`）。

## 电子台历

主界面点「电子台历」进入，一天一页，支持「前一天 / 后一天」翻页；非今天页面会显示「回到今天」。

- 每页显示当天公历日期、农历日期、星期和当前所在节气。农历与节气按北京时间计算，不依赖第三方库。
- **只有今天页面**显示当前时间（为保护墨水屏，只显示时分、不显示秒；对齐系统时钟的整分钟刷新，与状态栏一致）；翻到其他日期则隐藏时间。今天天气（图标 + 天气文字 + 温度）显示在该日期时间区域的左侧空白处。
- 天气数据来自 Open-Meteo（免费、无需 key），首次打开会按公网 IP 粗略定位城市；点城市按钮输入名称，会自动列出候选城市（城市 · 省份 · 国家，同名城市可区分），点选后即切换并刷新天气，所选城市会持久保存。城市搜索用 Photon（OpenStreetMap 数据，中文地名比 Open-Meteo 自带的 geocoding 准确，能搜到江油等县级市、避免珠海/兰州混入外省同名地点），只列行政区/城镇、过滤车站机场等 POI 并按名称去重。
- 天气按**横向多列**排列，7 列在一屏内全部显示、无需滑动；列与列之间留有小间隙；每列用图标 + 天气文字 + 日期 + 最高/最低温度展示。
- 未来一周天气只显示**明天起 7 天**（今天天气已在日期时间区域左侧单独显示，不再重复列入）；未来 1～7 天的日期页只显示该日期当天的预估天气；超出未来一周及过去的日期不显示天气。
- 每次唤醒（回到）台历页都会刷新天气；若一直停留在前台，则每小时自动刷新一次。「刷新」按钮可随时手动获取。
- 天气结果缓存作离线兜底；设备需连接可访问互联网的 Wi-Fi。

## 其他

- 图片库按接收时间倒序排列；应用不会自动删除已接收文件。
- 界面使用黑白高对比、无动画，适配电子墨水屏。
- 图片放在 `Pictures` 而不是 `DCIM`：前者是普通图片的标准目录，后者主要给相机使用。
