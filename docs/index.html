01 / 功能

小屏幕，也能做很多事。

每个功能都按电子墨水屏的习惯重做了一遍：字大、对比强、操作直接。

01

给Kindle发送图片

手机、电脑或 Pad 都可以传。连上同一个 Wi-Fi，扫主页二维码或打开主页地址，选好几张照片点上传，Kindle 会自动全屏打开最后一张。图片保存在系统相册可见的「Pictures」目录，不会悄悄消失。

  • 手机 / 电脑 / Pad 均可上传
  • 支持一次上传多张图片
  • 宫格浏览，左右滑动切换
  • 点按显示「旋转 90°」，边缘滑动返回

02

待办清单，多端都能改

在 Kindle 上勾，或者用手机、电脑、Pad 的浏览器打开同一个地址添加待办，数据就在同一份清单里。未完成、已完成、已删除三个标签页，删掉的东西还能找回来。

  • 设备端、手机 / 电脑 / Pad 共享同一份待办
  • 添加、修改、删除，删除前二次确认
  • 「已删除」可恢复，再次删除才彻底清除

03

会漏沙的倒计时

5、10、15、30 分钟和 1 小时一键开始，也能用滑条在 1～60 分钟之间自己定。沙漏上半显示剩余、下半显示已用，沙子随时间匀速落下。

  • 暂停时沙漏和沙流一起停下
  • 退出页面自动暂停，回来点「继续」接着走
  • 结束后显示本次耗时与累计耗时
  • 底部常驻日期和时间
真机实测界面
04

一页一天的电子台历

公历、农历、星期和当前节气排在一页上。今天显示时分，翻到其他日期就自动隐藏时间；天气按一周横向排开，还能搜索切换城市。开机放在桌上，就是一块安静的日历屏。

  • 农历与节气按北京时间计算
  • 今天天气 + 未来 7 天预报
  • 城市可搜索切换并保存
  • 天气数据来自 Open-Meteo，需联网获取
真机实测界面
05

给 AI 助手的 MCP 接口

Kindle 自己就是一个 MCP 服务器。AI 助手能读待办、图片、计时和台历，也能替你添加待办、上传图片、控制计时。和网页共用 8088 端口，不用另装服务。

  • 8 个 Resources 读取，18 个 Tools 写入
  • Streamable HTTP + JSON-RPC 2.0，无需会话
  • 可选 Bearer token，默认仅在局域网内使用
  • 主页「AI 助手操作指南」一键复制配置指令
MCP · tools/callPOST /mcp
{"jsonrpc":"2.0","id":7,
 "method":"tools/call",

  "name":"add_todo",
  "arguments":{
    "title":"让 AI 加的待办"
  }
 }}

03 / 使用方式

三步，就能开始用。

不用账号，不用云服务。准备好设备，装好 APK，扫个码就行。

  1. 1

    准备设备

    Kindle Paperwhite 3（DP75SDI，系统 5.16.2.1.1）。先按 kindlemodding.org 越狱一次，再照 Readom 安装教程 装好 Android 8.1。

  2. 2

    安装助手

    下载 APK 安装到 Kindle，首次启动允许存储权限，再把「Kindle助手」图标加到主屏幕。

  3. 3

    扫码使用

    手机、电脑或 Pad 与 Kindle 连接同一个 Wi-Fi，扫主页二维码或打开主页地址，就能传图片、管理待办。

越狱与 Readom 安装请分别参考 kindlemodding.org 和 Readom 安装教程。安装 Readom 推荐使用 AI 助手：把 写给 AI 助手的安装说明 发给它，电脑侧的步骤可以全部交给它。越狱与本项目无关，风险自行判断。

04 / 安装

为哪块屏幕做的？

目前只适配一台设备。先把范围说明白，比装不上再排查要省事。

设备
Kindle Paperwhite 3（第 7 代，DP75SDI）
系统
5.16.2.1.1，需已越狱并运行 Readom（Android 8.1）
前提
越狱中 sh_integration 可用；设备存储剩余 2.6 GB 以上
网络
传图、待办在同一局域网即可；电子台历天气需联网获取
推荐

让 AI 助手来装 Readom

Readom 官方有一份写给 AI 助手的安装说明。把它发给 AI 助手，电脑这一侧的下载、校验、把文件拷进 Kindle 都可以交给它完成；插线、唤醒、点按这些设备上的操作仍由你来做。

Readom 与本助手是两个独立项目。设备越狱按 kindlemodding.org 做一次；Readom 安装见 readom.app 的安装教程。越狱与本项目无关，风险自行判断。

通过 adb 安装 APK
adb install -r KindleAssistant.apk

也可以把 APK 拷进设备后，用文件管理器直接打开安装。

05 / 常见问题

你可能想问的。

还有别的疑问，欢迎反馈到 forreallab@126.com。

支持哪些 Kindle？

目前适配 Kindle Paperwhite 3（DP75SDI，系统 5.16.2.1.1），并且设备已经越狱、能运行 Readom 的 Android 8.1 环境。其他机型暂未验证。

需要一直联网吗？

传图和待办不需要外网。接收服务监听在 Kindle 的 8088 端口，手机、电脑或 Pad 与 Kindle 连同一个 Wi-Fi 就能传图、添加待办；建议只在可信的局域网里使用。电子台历的天气需要设备连上可访问互联网的 Wi-Fi，数据来自 Open-Meteo。

图片会存在哪里？

保存在内部存储的「Pictures」目录，系统相册可见，文件名带时间戳。应用不会自动删除已接收的图片。

待办事项会丢吗？

待办保存在应用内部文件 todos.json，重启后仍在。删除先进入「已删除」，可以随时恢复；在「已删除」里再次删除才会彻底清除。

AI 助手怎么连接 Kindle？

在 Kindle 主页点「AI 助手操作指南」，页面会按当前 IP 生成 MCP 地址 http://<Kindle-IP>:8088/mcp 和一段配置指令，复制发给 WorkBuddy 即可自动添加；豆包需要用工作版手动添加。该接口可读写设备上的全部数据，建议设置 Bearer token，并只在可信局域网内使用。
